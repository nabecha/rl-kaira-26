# 進化するAIサッカー ゲーム本体

このフォルダにゲームで使うシーン・スクリプト・キャラクター・フィールド・モデルを集約しています。
旧 `Assets/KaiRASoccer` と `Assets/ML-Agents` の必要なアセットは、`.meta` のGUIDを保って移動済みです。

## 起動

`Scenes/SoccerStartMenu.unity` を開いてPlayを押してください。
メニュー **KaiRA → ゲームを開く（Build Settingsを設定）** からも開けます。
スタート → 対戦 → 結果・ランキング → スタートの3シーンを使用します。
対戦画面では、人間が操作するキャラクターの体を黄色で表示します。

## スタート画面の8面デモ

左側にメニュー、右側にプレイ画面と同じ3Dフィールド・KaiRAキャラクターの対戦を表示します。
`Soccer/Prefabs/SoccerFieldTwos.prefab` を実空間に2列×4行で配置し、
プレイ画面と同じカメラ角度・画角、背景色、照明・影を使って斜め上から映します。
映像上部の「8面全体」で全スタジアムを、「1」〜「8」で各スタジアムを拡大表示できます。
各スタジアムは2対2で独立して動き、ゴール後も対戦を繰り返します。
キーボード・コントローラーでレベルにカーソルを合わせると、対応モデルがデモの全32選手に反映されます。
「デモのモデル」では、対戦のレベルとは別に観戦用モデルを選択できます。
「デモを停止」ボタン、Pキー、コントローラーの□でデモを停止・再開できます。
停止中はAI推論・物理演算を止めます。ビルド版では描画も30fpsを目標に制限して負荷を抑えます。
停止中もレベル選択・ランキング・対戦開始を操作でき、対戦から戻ってもデモの停止状態を保持します。
キャラクターの見た目は対戦シーンと同じ `KaiRAVisualSwapper` で差し替えます。
試合結果・ランキングには影響しません。
学習済みモデルの推論によるデモで、追加学習は行いません。

## フォルダ

- `Characters`: KaiRAのプレハブ・メッシュ・マテリアル・見た目差し替えとしっぽのアニメーション。
- `Soccer`: ゲーム処理、フィールド、ボール、学習済みモデル。
- `Shared`: ゲームから参照されるML-Agents共通アセット。
- `Scenes`: スタート・対戦・結果の3シーン。
- `Editor`: 起動・Build Settings設定メニュー。
- `KaiRASoccerModelMenu.cs`: 5段階のレベル選択・デモ用モデル選択とランキング表示。
- `KaiRASoccerStadiumPreview.cs`: スタート画面の8面デモと観戦カメラ。

## 学習済みモデル

対戦ではレベル1〜5に順に499,706・1,999,860・3,999,998・7,999,989・18,858,676 stepのモデルを使用します。
レベルは「レベル1（学習時間：20分）」の形式で表示し、学習時間は順に20・80・160・320・754分です。
表示時間は50万step＝20分として換算し、分単位に四捨五入しています。
人間操作以外の全AIに同じモデルを適用し、ランキングもレベルごとに保存します。
旧3難易度のランキングは保持し、新しい5レベルのランキングとは分けて管理します。
`Soccer/TFModels` のステップ数付き38モデルは、スタート画面の「デモのモデル」で観戦用に選択できます。
ステップ数のない3モデルも、フィールドの既定モデル参照に必要なため残しています。
モデルはシーン内の参照を通じてビルドに含まれます。
モデルを追加する場合は、スタートシーンの `KaiRASoccerModelMenu` の `Models` 配列にも登録してください。

Unityのバージョン、操作、ビルド、GitHubに含める範囲は、リポジトリルートの `Readme.md` を参照してください。
`Project/Packages`、`Project/ProjectSettings` とルートの `com.unity.ml-agents` も実行に必要です。
